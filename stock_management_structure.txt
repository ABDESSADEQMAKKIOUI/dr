Cette structure représente un système complet de gestion d'entreprise (ERP léger) qui sera très compétitif sur Envato Market.

# 1. Aller dans le dossier backend
cd c:\Users\Asus\Desktop\call\facturation

# 2. Installer les dépendances
composer install

# 3. Configurer l'environnement
copy .env.example .env
php artisan key:generate

# 4. Configurer la BDD dans .env
# DB_DATABASE=erp_saas
# DB_USERNAME=root
# DB_PASSWORD=

# 5. Créer la base de données MySQL
mysql -u root -p
CREATE DATABASE erp_saas;
EXIT;

# 6. Exécuter migrations + seeders
php artisan migrate --seed

# 7. Créer lien storage
php artisan storage:link

# 8. Lancer le serveur
php artisan serve
